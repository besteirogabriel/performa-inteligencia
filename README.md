# Performa Inteligência Organizacional — Redesign

Redesign institucional completo do site da Performa Inteligência Organizacional.

## Estrutura

- `index.html` — landing page institucional
- `styles.css` — sistema visual e responsividade
- `script.js` — navegação mobile e animações discretas
- `assets/performa-symbol.svg` — novo símbolo vetorial
- `assets/performa-logo.svg` — nova assinatura horizontal
- `.github/workflows/pages.yml` — deploy automático no GitHub Pages

## Identidade

O símbolo parte de um **P** construído como um fluxo organizacional: uma estrutura principal recebe duas linhas internas, representando processos e informação convergindo para uma operação única. O contraste entre grafite e verde-amarelado marca a diferença entre estrutura e impulso/performance.

## Publicação

O repositório foi preparado para GitHub Pages via GitHub Actions. Depois de criar o repositório, basta enviar o conteúdo para `main` e ativar Pages com **Source: GitHub Actions**.
